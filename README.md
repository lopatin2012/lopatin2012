### Проекты

**Продакшен**

- **[free_digital_marking](https://github.com/lopatin2012/free_digital_marking)** — интеграция с «Честным ЗНАКом»: True API/СУЗ, жизненный цикл кодов, привязка к партиям, отчёты о нанесении.
- **[VerificatorDataMatrix](https://github.com/lopatin2012/VerificatorDataMatrix)** — верификатор DataMatrix по ISO/IEC 15415: грейдинг, PDF-отчёты, web-интерфейс, fallback-локатор на нейросети.
- **[signature_service](https://github.com/lopatin2012/signature_service)** — микросервис электронной подписи CAdES-BES на FastAPI: Windows (CAdESCOM) и Linux (КриптоПро CSP).
- **[PrintingMachine](https://github.com/lopatin2012/PrintingMachine)** — сервис печати групповой этикетки для производственной линии.
- **[PartyManagementSystem](https://github.com/lopatin2012/PartyManagementSystem)** — система управления партиями.

**Инструменты и open-source**

- **[production-line-sim](https://github.com/lopatin2012/production-line-sim)** — симулятор производственного участка на чистом Python: виртуальная линия, принтеры Zebra/TSC (ZPL), HMI, шина событий.
- **[VisoMaster-Modern](https://github.com/lopatin2012/VisoMaster-Modern)** — форк VisoMaster: AI-замена и редактирование лиц, современный UI (PySide6), адаптация под CUDA 12.9 / Blackwell.
- **[gameDM](https://github.com/lopatin2012/gameDM)** — кликер про внедрение маркировки DataMatrix на vanilla JS, без сборки.
